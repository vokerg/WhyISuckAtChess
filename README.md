# Why I Suck at Chess

A lightweight, evidence-driven chess diagnosis product built to answer one question in depth:

> **Why do I suck at chess?**

The canonical product and engineering foundation is maintained in [BIBLE.md](BIBLE.md).

This repository is intentionally starting with product invariants and diagnostic scope before implementation planning. The existing [`vokerg/chess_repertoir_trainer`](https://github.com/vokerg/chess_repertoir_trainer) project is the primary reference implementation for stack, authentication, Lichess integration, imported-game processing, Stockfish analysis, chess UI, and engineering procedures; this project is not intended to be a fork of it.
